# 商品库历史图片入口修复

商品库图片保存在 NAS 图片专用服务。中控服务器的 `/rpa/v1/product-images/` 只读入口必须转发到该服务的私网端口 `25490`；`3612` 是已停用的旧商品库网页端口，不可作为图片上游。

2026-11-14 排查发现正式入口指向旧端口，商品库上传接口返回的历史 IP 图片地址因而读取 502。已在服务器修正入口并备份原配置，域名及历史 IP 入口均可读取同一张 NAS 图片，网页规格图上传后能正常加载。商品数据未修改。

本次源码同步修正中控发布脚本和对应发布测试，避免后续发布重新渲染旧端口。源码合并和正式发布状态以实际记录为准；只更新源码或运行测试不代表后续发布已生效。

## 验证与回滚

- 隔离容器内执行 `scripts/test-remote-deploy-production.sh`，通过既有发布及回滚相关测试（包括 19 项模拟容器状态检查）；未连接生产数据库。
- 此改动不涉及数据库迁移、商品数据、NAS 图片文件或认证；回滚此源码提交可恢复旧值，但只有在旧网页端口重新提供图片服务时才应这样做。
- 正式服务器当前已单独修正并验证。下次中控发布前必须将此修复纳入已审核的发布版本，否则旧脚本会再次写回错误端口。
