## 状态口径

| 状态 | 含义 |
|---|---|
| `NOT_STARTED` | 尚未开始实现 |
| `IN_PROGRESS` | 正在按 Feature / Gate 流程开发或验收 |
| `BLOCKED` | 有明确外部前置阻塞 |
| `PARTIAL` | 已有正式能力，但范围或真实验收未完整覆盖 |
| `UI_ONLY` | 仅界面或导航占位，未形成对应正式执行契约 |
| `DONE` | 已完成代码与相应 Gate，尚未作为生产验收项记录 |
| `DEPLOYED` | 已发布并在生产完成记录所列验收 |
| `DEFERRED` | 已明确延后，当前不进入实现 |

## 维护规则

生产跨版本客户端兼容修复 V1：`IN_PROGRESS`。恢复参数列表数组兼容、保留 PC 哈希资源与显式更新提示；Gate 2 后待用户验收，尚未发布。

- 新功能、状态转换或目标版本调整必须有对应代码、Gate、验收或明确阻塞证据；不得仅根据聊天结论更新。
- `DEPLOYED` 必须同时记录实际生产 SHA 或等价的可追溯发布事实，以及验收范围。
- `PARTIAL`、`UI_ONLY` 与 `DEFERRED` 必须在备注写明边界，避免被误读为可生产使用的完整能力。
- 本表描述范围与状态，不替代 `docs/09-Production部署与发布.md` 的部署步骤，也不替代各子系统的 API / 数据库 / Worker 契约文档。
