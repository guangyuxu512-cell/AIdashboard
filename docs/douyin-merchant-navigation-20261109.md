# 抖店商家后台入口

商品库使用中控授权店铺查询抖店类目时，HuanYu 的罗盘身份验证可用，但商品接口返回 `10008`。对同一已核验店铺，使用相同中控状态与同一请求分别从电脑和 NAS 发送，均返回该错误；与商品库正式接口结果一致。同店成功浏览器状态仅在内存中补足一项商家后台认证信息后，类目查询成功。以上证据不证明平台何时改变要求，也不证明历史版本为何能通过。

已有抖店的中控登录窗口在罗盘识别成功时同步当时状态，保留的窗口仍拒绝新窗口；用户无法可靠进入商品发布页。本候选在已有抖店同步成功并保留的窗口增加固定菜单入口，由用户在同一 Profile 打开抖店商品发布页并自行处理平台登录。菜单不改变 Session 采集、身份校验、持久化或权限，也不接收外部 URL。用户完成后关闭窗口并重新从中控登录，复用既有同步；没有同步前不能将新页面状态视为已保存。
