# 1688 账号状态

1688 采集程序独立领取和执行运营中心任务，通过现有运营中心 Worker Token 上报不含 Session、Cookie、密码的数据。运营中心保存每个安装实例的最近心跳和本机账号状态；90 秒未上报显示离线，离线不会改写上次会话结果。

中控店铺状态页复用共享表格，新增管理员可见的「1688 账号」视图。由于 1688 安装实例不绑定中控 Team，接口仅允许人类超级账号，通过既有运营中心服务凭据读取，普通成员和 API Token 不能跨团队读取。会话校验时间过旧或缺失时不显示为当前有效。

1688 软件的签名发布包通过运营中心的同一 Worker Token 只读分发；中控网关对该路径关闭缓冲。中控不下载 1688 Session，不负责其进程执行和任务调度。
