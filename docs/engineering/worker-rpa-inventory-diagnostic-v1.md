# Worker 本机 RPA 店铺清单诊断

`system.rpa_inventory_diagnostic` 是使用现有签名能力包机制的只读诊断，输入为空对象。它检查同一系统用户下的 RPA 发现文件、数据库与受信辅助程序，并复用现有店铺清单接口。结果只包含固定错误码、布尔状态、店铺数量及合规版本；辅助程序不受信时返回程序文件的 SHA-256 指纹供核对发行包，不返回路径、店铺身份、Session 或凭据，不启动浏览器、不请求平台。

错误码区分发现文件缺失或无效、路径不匹配、安装文件缺失、辅助程序不受信及现有桥接错误；`RPA_INVENTORY_READY` 表示读取店铺清单成功。该能力不改变已有信任校验和任务权限，供排查时按设备定向执行；无需迁移或新增服务。
