# Worker 本机会话恢复：Gate 1

- 基线：Green dev `38280a109e4717d3d347e2741e06623b6c6496df`。无中控 API、表或 Migration 变化。
- Worker 只向受信任的本机 RPA 请求固定店铺的会话恢复；不上传 Session。网络异常和身份不明不标记为失效，补取按店铺及快照限频。旧 RPA 不支持时不耗尽恢复次数。
- 实机样本中未确认店铺的抖店、罗盘身份接口分别返回 10008、10012，均未提供明确登录失效文字。只在两侧服务可达且快照未确认罗盘时尝试一次后台补取，状态仍为未确认；网络异常或同店身份不符不触发该尝试。
- 仅罗盘需补取时，失败不覆盖可用会话；抖店会话缺失或明确失效时，允许先恢复并保存同店抖店会话。快照变更后旧结果不能覆盖新结果。
- Worker 相关测试已通过；RPA 候选、隔离启动及桥接测试需一并交付。真实设备的隔离运行中，HuanYu 无头补取并在隔离副本验证同店罗盘成功；另一店的 RPA 判为需人工验证，未保存新快照。正式组合与发布后的自动更新仍需验证。
- 回滚：停用该 Worker 版本并按现有签名更新机制回退，保留设备身份、店铺资料和 Session；RPA 保留旧版以便回退。发布前需将新旧 RPA 桥接程序摘要同时加入受信清单，避免中断现有预检。
