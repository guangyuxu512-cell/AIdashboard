# Worker 店铺状态总览

中控按既有设备数据权限读取各设备的本机店铺清单。相同平台店铺在多台设备上分别展示，登录状态不跨设备推断；设备离线时保留最后上报和验证时间。页面不登记、绑定或存储店铺 Session。

Worker 使用本机 RPA 快照沿现有轮询逐店验证抖店身份与罗盘身份；两者独立记录。同店正在执行预检或请求时不并发验证，其他店可以继续验证；选品间隔足够时可利用同店等待间隙验证，请求开始前仍会终止冲突验证。自动补取会话仍只在设备无任务时启动。成功结果最多显示为当前有效 30 分钟，Worker 在 15 分钟后开始安排复验；无明确登录失败时不标记失效。失败和成功结果只属于相同本机快照，快照变更后重新验证。

当相同快照的上次有效结果已超过 30 分钟而尚未完成复验，API 仍返回 `unknown`，验证时间保留上次真实时间，页面显示“待复验”；从未验证仍显示“未确认”。同一快照偶发缺少罗盘验证标记时保留上次标记，新快照或明确的反向结果不继承。运营中心现有资格判断仍按原契约执行，不能把待复验当成明确失效，也不能把待复验当成一次新的成功验证。

新增可选罗盘状态与时间字段仅包含状态和时间；没有新表或 Migration。旧 Worker 显示罗盘未确认；新 Worker 对旧中控的清单兼容保留既有抖店状态。先发布兼容中控，再通过受信任底座更新通道分发 Worker；保留设备身份及本机资料，更新失败回退。
