# Worker 店铺状态总览

中控按既有设备数据权限读取各设备的本机店铺清单。相同平台店铺在多台设备上分别展示，登录状态不跨设备推断；设备离线时保留最后上报和验证时间。页面不登记、绑定或存储店铺 Session。

Worker 使用本机 RPA 快照，空闲时沿现有轮询逐店验证抖店身份与罗盘身份；两者独立记录。成功结果最多显示为当前有效 30 分钟；无明确登录失败时不标记失效，网络错误不清除有效期内的上次结果。失败和成功结果只属于相同本机快照，快照变更后重新验证。已确认结果低频复验，未确认服务按原未知状态节奏重试，优先不影响正在执行的任务。

新增可选罗盘状态与时间字段仅包含状态和时间；没有新表或 Migration。旧 Worker 显示罗盘未确认；新 Worker 对旧中控的清单兼容保留既有抖店状态。先发布兼容中控，再通过受信任底座更新通道分发 Worker；保留设备身份及本机资料，更新失败回退。
