## 2. 固定运行规则

- Main 的 Backend/PC Frontend 固定为 `8000/5173`；Integration 固定为 `8100/5180`；AI Frontend 为 `5174`；SSH Tunnel 为 `35433`。
- Vite 启动必须显式指定端口并使用 `--strictPort`，冲突即停止，禁止自动换到其他端口。
- Integration Electron 如确需联调，`FRONTEND_DEV_SERVER_URL` 只能指向 `5180`；不启动第二个 Electron，也不得占用 Main 的 `5173`。
- Mobile 应从当前 `mobile` 配置读取实际启动方式/端口；上表只记录本次审计到的 `dev:visual` 配置，非跨团队端口保留声明。
- Main 的 `.dev-runtime/` 只管理其写入的精确 PID；过期 PID 文件、PID 重用或日志残留必须用进程命令和端口复查后处理。

## 3. 数据库隔离

| 角色 | 可写数据库 | 禁止 |
|---|---|---|
| Feature | 自己可重建的临时/Feature DB | 写 Integration、Main smoke、生产数据库 |
| Integration | `control_center_integration` | 写 Main smoke 或生产数据库 |
| Main smoke | `control_center_dev` | 作为 Feature/Integration 的共享测试库 |
| Production（未来） | 独立生产库 | 用于开发、Smoke、Migration 试验 |

实际连接串只存本机受忽略环境文件；本表绝不记录数据库密码、完整 URL、Token 或 SSH 私钥。

## 4. 本地 Integration 覆盖

Integration Worktree 的 `AGENTS.override.md` 是本机运营说明，不属于仓库内容。该 Worktree 使用 Git worktree 配置的 `.codex/git-exclude` 忽略 `/.codex/` 与 `/AGENTS.override.md`，应通过 `git check-ignore -v AGENTS.override.md` 验证；不得把该覆盖、任何 `.env` 或运行状态加入暂存区。
