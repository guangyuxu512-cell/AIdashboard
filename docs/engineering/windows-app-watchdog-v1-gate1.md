# Windows 软件守护 Gate 1

- 基线：Green dev `3f6c83d817be63afb0dabb99da2793d6b66eb941`。本 Feature 无数据库、API、迁移或中控 Web 前端改动。
- 独立当前用户看门狗，用户选择普通程序、Windows 服务、Worker、1688、比特及采集插件；登录启动项和守护互监不需要管理员权限。UU 可选其现有 `GameViewerService`。
- Worker `0.5.25` 增加持久活动检查点；仍复用现有心跳、任务租约、Outbox 和签名更新机制。网络故障不结束进程；缺少安全空闲证据或结果不确定时不自动启动。
- 1688 活动检查点需配套 `1688-Sourcing` 的 `0.1.11`；自动恢复前核验已生效的签名版本和文件，更新回滚、旧版及没有签名更新记录的首次安装视为状态未知。采集插件使用运营中心既有只读心跳，令牌由本机 DPAPI 保护；插件心跳和比特 API 错误不会触发浏览器关闭。
- 通用任务型软件（如未适配的聚水潭上架）只监测、不会在状态不明时自动重启。浏览器启动不等于插件已在线；守护不操作浏览器标签、不提交任务。
- 验证：Worker 与看门狗离线回归、Windows 双进程自恢复与退出、本机登录启动权限、Electron/1688 检查点跨语言契约、独立发行包与 Worker 包自检；真实设备及生产更新状态另行验收，不以本地测试替代。
- 回滚：停止并移除独立看门狗自启项；Worker 可经既有签名发布流程恢复兼容旧版。不得删除设备绑定、用户资料、Session、Outbox 或已选软件配置。
