# 商品属性字段提示契约

- `douyin.category_schema` 的 `items[].placeholder` 是平台返回的可选字段提示；仅保留长度不超过 500 的字符串。它不包含属性填写值；缺失或未知形状不代表平台没有提示或其他规则。
- 中控结果校验接受该可选字段并继续拒绝非字符串、超长提示和未知商品数据；旧调用及不含提示的结果保持兼容。商品库负责消费和展示这一可选元数据。
- 现有脱敏样本 `1000005146`、`1000001535` 证实了该字段；截图类目 `1000005147` 与服装类目 `1000010274` 尚无完整原始响应，不据此宣称其他属性、联动或图片规则完整。
- 发布顺序：先部署接受该字段的中控，再通过既有签名流程发布新版本 `douyin.category_schema` 能力包并确认设备实际加载，最后由商品库接入提示。旧设备仍运行旧能力时，响应可能不含提示；不得将其视为已加载新能力。
- 本次不更改 Worker 底座、任务并发、店铺会话、数据库或 Migration。`prefix_id`、`suffix_id`、`extra.unit_rule_type` 的业务语义尚未确认，非空 `unit_rules` 和 `unit_linkage` 仍保留未知标志，不把未知规则判为已验证。
