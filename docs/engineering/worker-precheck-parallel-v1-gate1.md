# Worker 商品预检并发

- 基线：Green dev `c0bbab976155b3294ec5a48b947e477a1f364261`。无数据库结构变化、无 Migration Slot。
- 范围：每台 Worker 最多 5 个店铺、每店最多 3 个并发；相同平台店铺在多台设备上合计不超过 3 个。普通 RPA 任务仍独占设备并按原队列执行；预检结果继续由 Worker 直传商品库。
- 在线设备自动参加需商品库应用授权显式启用 `all_precheck_devices`；测试设备继续通过排除清单隔离。旧授权默认行为不变。失效 Session 判断与轮换规则沿用现有实现。
- 验证：独立 Feature PostgreSQL（Head `20261113_0051`）预检相关集成测试 23 通过，旧 0050 迁移专属库测试在此库跳过；覆盖 5 设备、25 店、75 个实际数据库并发领取、同店跨设备限额、普通任务互斥与队列公平。Worker 完整测试通过；另验证断网时结果留存并在恢复后直传、不重复执行。Windows Worker `0.5.5` 构建通过，包内版本与能力包公钥检查通过。
- 回滚与限制：先部署兼容 Backend，再在设备空闲时升级 Worker；旧 Worker 保持单任务兼容。回滚可关闭新增授权并恢复旧 Backend/Worker；不得中断运行中的任务或清除设备身份、店铺资料。五台设备和真实平台 75 并发目前是隔离测试结果，尚非生产运行证据。
