## 实现与边界

“更多筛选”固定为：曝光、点击量、点击率、加购量、加购率、真实订单、异常订单、转化率、退款率。
筛选顺序直接从既有 `PRODUCT_DISPLAY_COLUMNS` 核心展示元数据派生；区间配置只按语义 ID 保存边界，
不再维护第二份展示顺序。预设值、自定义上下限、`[min,max)`、百分比输入 1 表示 1%、
错误保留、查询过滤、折叠后草稿、分页和字段拖动／固定顺序成果均保持。

九项改为等宽 CSS Grid：可用宽度依次使用 5／4／3／2／1 列；现有紧凑控件高度和间距不变。
删除的只有常驻说明“区间含下限、不含上限……百分比填 1 表示 1%”，没有删除校验反馈或更改语义。

页面灰色“基准售卖切片／基准载体切片”当前并非已接通的可选维度。
Frontend Real、Backend schema／source 和 0047 存储切片均固定 `sale_type=1`、`content_type=1`，
所以本轮继续禁用选择，仅表示当前基准切片。未来启用至少需要平台枚举与真实请求证据、正式 API 查询契约、
解析映射以及迁移／存储切片和唯一性设计，必须另立任务。

改动仅限商品数据前端源码、定向测试和契约文档；无 Backend、API、数据库、0047、Migration、
Electron、Worker、Mobile、依赖、锁文件、平台请求或生产变化。
