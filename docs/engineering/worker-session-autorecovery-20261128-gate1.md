# Worker 会话自动恢复 Gate 1

- 基线：Green dev `d9b8732b1280eebc5e9c23a139a29b3486bceaa5`；Worker 版本 `0.5.22`。
- 范围：Worker 本机会话复核、现有 RPA 刷新桥与状态上报；不改变 Skill 的输入输出、任务执行并发、失败结果回传或 RPA 登录实现。
- 失效判定：任务提示登录失效后复核本机同店快照；商品接口业务拒绝仅限频触发身份复核，不等同失效。身份接口明确返回登录失效，或本机确认无快照，才调用 RPA 补取；未知、网络异常或一般业务拒绝不会判失效。旧结果不能覆盖新快照，设备忙时等待任务结束。
- 重试：沿用 RPA 刷新结果、按快照的间隔与次数限制；需要人工验证时不反复尝试。状态上报断网不阻断本地恢复。新快照必须重新验证；任务本身不会因刷新自动重放。
- Migration：无。数据库：无。本次测试不连接生产平台、不读取真实 Session、不执行真实采集或更改用户资料。
- Gate 1：Worker 全量 287 项测试通过；针对失效、业务拒绝、网络异常、并发、优先复核取消、断网上报和快照替换的 49 项定向测试通过。Windows 发行包已通过 `scripts/test-worker-package.ps1`，包含版本、信任公钥与运行时导入检查。
- 未覆盖：没有人为使生产店铺会话失效；真实平台验证码或人工校验取决于平台与设备现场，RPA 返回 `manual_required` 后不会自动绕过。
- 回滚：Worker 自动更新保留此前受信任版本，发布前须核对现网签名序号、设备空闲与可回退版本；如需回退按既有签名发布流程发布较高序号的已验证旧代码，不能降签名序号或删除店铺资料。
