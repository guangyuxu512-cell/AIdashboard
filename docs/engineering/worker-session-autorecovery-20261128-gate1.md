# Worker 会话自动恢复 Gate 1

- 基线：Green dev `d9b8732b1280eebc5e9c23a139a29b3486bceaa5`；Worker 版本 `0.5.22`。
- 范围：Worker 本机会话复核、现有 RPA 刷新桥与状态上报；不改变 Skill 的输入输出、任务执行并发、失败结果回传或 RPA 登录实现。
- 失效判定：商品预检、商品管理或罗盘任务明确登录失效时，校验任务执行前后使用的是同一快照；本机持久保存恢复证据，重启后继续。同一快照必须是实际平台登录失效；预检合成的 skip 不计。商品接口业务拒绝仅限频触发身份复核，不等同失效。身份接口明确返回登录失效，或本机确认无快照，也可调用 RPA 补取；未知、网络异常或一般业务拒绝不会判失效。旧结果不能覆盖新快照。
- 重试：沿用 RPA 刷新结果、按快照的间隔与次数限制；尝试次数和退避跨重启保留，明确未启动 RPA 不计次数，回执丢失按已尝试处理。需要人工验证时不反复尝试。其他店任务不阻断刷新，同店任务在刷新异步结束或有界超时前等待；受理前先持久记录刷新进行中，Worker 重启后从启动时恢复同店等待，`busy` 不当作完成。状态上报断网不阻断本地恢复，重放失败证据保留真实发生时间。新快照必须重新验证；任务本身不会因刷新自动重放。
- Migration：无。数据库：无。本次测试不连接生产平台、不读取真实 Session、不执行真实采集或更改用户资料。
- Gate 1：Worker 全量 301 项测试及 74 项定向测试通过。验证涵盖失效、业务拒绝、网络异常、并发、优先复核取消、断网上报、跨重启恢复和快照替换。Windows 发行包另按 `scripts/test-worker-package.ps1` 检查版本、签名信任与运行时导入。
- 未覆盖：没有人为使生产店铺会话失效；真实平台验证码或人工校验取决于平台与设备现场，RPA 返回 `manual_required` 后不会自动绕过。
- 回滚：Worker 自动更新保留此前受信任版本，发布前须核对现网签名序号、设备空闲与可回退版本；如需回退按既有签名发布流程发布较高序号的已验证旧代码，不能降签名序号或删除店铺资料。
