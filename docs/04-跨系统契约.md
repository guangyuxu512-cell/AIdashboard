# 跨系统契约

## Frontend ↔ Backend
以 Backend Pydantic/OpenAPI Contract 为权威来源。
Frontend 不自行发明字段。

## Frontend ↔ Electron
通过 Preload 暴露有限、类型化 API。
Renderer 不直接使用 Node/Electron 原生模块。

## Backend ↔ Worker
统一 Device Registration、Heartbeat、Claim、Lease、Task Status、Result、Logs、Artifacts。

## Worker ↔ Skill/RPA
统一输入：
- task_id
- skill_id
- shop_id（需要时）
- params
- runtime context

统一输出：
- status
- result
- error_code
- error_message
- artifacts

禁止每个 RPA 自定义完全不同的通信格式。
