# 总体架构

```text
Vue Frontend
    │
    ├──── HTTP ────> FastAPI Backend ────> PostgreSQL
    │                       │
    │                       ├── Redis（按需）
    │                       ├── MinIO/S3（按需）
    │                       └── AI Analysis（按需）
    │
    └──── Preload / IPC ───> Electron Main
                                  │
                                  └── Process Manager
                                          │
                                      Worker
                                          │
                      ┌───────────────────┼───────────────────┐
                      ↓                   ↓                   ↓
                     RPA               Python               Node/EXE
```

设计目标：
- Frontend 可先 Mock，后续切真实 API。
- Electron 和 Worker 解耦。
- Backend 为模块化单体。
- PostgreSQL 是业务事实来源。
- Redis 是缓存/通知/协调能力，不替代事实库。
- RPA 是 Skill 执行能力，不承担任务调度。
