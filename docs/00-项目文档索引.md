| 新增核心实体 | 03-核心领域模型.md |

| 跨 Frontend / Backend / Electron / Worker 修改 | 04-跨系统契约.md |

| VPS 开发 Backend 部署与更新 | 08-VPS开发后端部署.md |

不要把前端样式、后端表结构、Worker RPA 细节写入根文档。

`10-功能清单与路线图.md` 是当前状态快照，不是阶段流水账。它必须分别标明“已进入
Green `dev`”“已进入 `main`”和“已有生产部署回执”；历史 Gate、CI、Migration、失败与
回滚证据继续保留在 `docs/engineering/`，不得用当前摘要覆盖或删除。
