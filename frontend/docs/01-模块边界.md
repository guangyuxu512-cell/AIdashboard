# 前端模块边界

推荐依赖方向：

```text
app
↓
pages
↓
features
↓
entities
↓
shared
```

禁止 shared 反向依赖 pages/features。

## Pages
只做页面组合和页面级协调。
禁止把请求、格式化、业务规则直接堆进巨大 Page 文件。

## Features
表达用户动作，例如：
- create-task
- bind-device
- refresh-session

## Entities
表达稳定业务对象，例如：
- ShopStatus
- DeviceStatus
- TaskStatus

跨 Shop、Product、Order、Data Center、Task 复用的平台展示定义归属 `entities/platform`。Shop Entity 只保留 Shop Contract、状态和 Shop 专属展示，不得再维护平台名称、图标或 Select Options。

## Shared
没有业务语义。

重复 2 次以上、跨页面复用、同一实体重复展示时必须优先抽离。

## Device Office 领域表现边界

`features/device-office` 负责设备 Visual State、固定 9 工位投影、本地视觉行为、2.5D 分层素材清单与 OfficeStage 组件；它只依赖 `entities/device` 的 View Model 和 shared/store 基础能力。`features/device-management` 继续负责真实设备详情、编辑、影刀 Discovery 与列表动作，`pages/devices` 只协调 Query 结果、视图切换、分页与 Drawer。2.5D Layer 禁止依赖 API/Data Source，`shared` 也不得反向依赖 Device Office。

设备中心正式路线是预渲染 3D 美术或 2D 动画素材加 Vue DOM/CSS 合成，不再使用 Three/Tres、WebGL 或 GLB Runtime。背景、前景、Actor 与 Screen 素材统一通过 `features/device-office/assets` 的 2.5D Manifest 接入；替换素材不得要求修改 Device / Worker View Model。
