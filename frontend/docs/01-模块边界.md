# 前端模块边界

推荐依赖方向：

```text
app
↓
pages
↓
features
↓
entities
↓
shared
```

禁止 shared 反向依赖 pages/features。

## Pages
只做页面组合和页面级协调。
禁止把请求、格式化、业务规则直接堆进巨大 Page 文件。

## Features
表达用户动作，例如：
- create-task
- bind-device
- refresh-session

## Entities
表达稳定业务对象，例如：
- ShopStatus
- DeviceStatus
- TaskStatus

## Shared
没有业务语义。

重复 2 次以上、跨页面复用、同一实体重复展示时必须优先抽离。
