# AI 模型管理 V1

## 1. 页面与权限

系统设置新增 `/settings/ai-models`“AI 模型管理”。页面继续复用 `SettingsLayout + SettingsSideNav`，只对当前 Team Context 的 `access_admin` 显示入口并允许路由访问；普通成员既看不到二级导航项，也会被既有 Router Guard 拒绝。

页面采用紧凑管理结构：`TableToolbar → DataTable → FormDialog`。工具栏提供状态筛选与“新增模型”，表格固定展示模型名称、Code、Provider、能力、输入上限、默认、状态和操作；不建立独立页面壳或 AI 私有基础控件。

## 2. Frontend Data Flow

```text
AiModelManagementPage
→ useAiModelManagement
→ TanStack Vue Query
→ entities/ai-model Data Source
→ /api/v1/ai-models
```

Real 与 Mock Data Source 使用同一 ViewModel 和写入 Contract。Mock 只复现正式初始化的 GPT Image 2 与相同默认规则，用于本地视觉和权限验证，不产生 Demo 模型语义。

新增/编辑复用 `FormDialog`、Naive UI Form 以及 Shared Input、NumberInput、Select、Switch。`model_code / provider_code` 创建后只读；启停、设置默认和默认模型冲突以 Backend Contract 为权威。

## 3. Boundary

本 Feature 不修改 AI Workbench，不增加模型下拉框，不向 Generation Submit 或 Generation Schema 添加 `model_id`，也不改变 Provider Adapter 的服务器配置选择。页面与 DTO 不包含 API Key、Base URL、Secret、Cost、Balance 或 Provider Payload。

这是 AI Model Management V1 初次交付的 Feature Boundary。后续 `AI Workbench Real API V1` 已按 Frozen Generation Contract 将启用模型目录接入工作台；模型管理页面自身仍遵守上述 Secret 与 Provider 管理边界。
