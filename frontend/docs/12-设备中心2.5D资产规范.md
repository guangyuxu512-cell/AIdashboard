# 设备中心 2.5D 资产规范

## 1. 正式路线

设备中心使用“预渲染 3D 美术或 2D 动画素材 + Vue/Electron 2.5D 前端合成”。页面是固定视角的办公区，不提供实时 3D、自由旋转相机、Three/Tres Renderer 或 GLB Runtime。

Device、Worker、分页、Query、Drawer 与 Backend Contract 不依赖素材文件名或动画格式。Backend / Worker 只提供真实设备数据和状态，不负责视觉动画。

## 2. 前端职责

`features/device-office` 负责：

- 固定 3×3 工位布局。
- `empty / onlineIdle / busy / offline / error` 前端视觉状态映射。
- 背景、工位、Actor、屏幕、前景遮挡和标签分层。
- 本地视觉行为选择与素材播放。
- 工位、标签到既有 Device Drawer 的交互。

视觉状态不得反写 Backend，也不得把本地 Idle、Walk、Coffee 等行为冒充真实 Worker Task。

## 3. 分层顺序

```text
DeviceOfficeStage
├── OfficeBackgroundLayer
├── OfficeSlotsLayer
├── DeviceActorLayer
├── DeviceScreenOverlayLayer
├── OfficeForegroundLayer
└── DeviceLabelLayer
```

`OfficeForegroundLayer` 用于桌面、植物等遮挡人物的透明前景素材；标签永远位于最上层。各层共享同一工位坐标，不得分别维护互不一致的 9 宫格。

## 4. 资产目录

```text
frontend/public/assets/device-office/
├── light/
│   ├── background.*
│   └── foreground.*
├── dark/
│   ├── background.*
│   └── foreground.*
├── actors/
│   ├── online-idle/
│   ├── busy/
│   ├── offline/
│   └── error/
└── screens/
    ├── idle/
    ├── busy/
    ├── offline/
    └── error/
```

机器可读 URL 清单位于：

```text
frontend/src/features/device-office/assets/office-2d-asset-manifest.ts
```

当前 SVG 是阶段 1 的统一风格占位资源，不代表最终美术验收。替换正式素材时优先保持 Manifest Key 和 Layer Contract 不变。

## 5. 后续素材形态

正式素材可以渐进采用：

- PNG / WebP 分层素材。
- Sprite Sheet。
- 透明序列帧。
- WebM 或 PAG（确认运行时、透明通道和性能后再引入）。

本阶段不强制定死最终动画格式。引入新格式前必须确认 Electron/Chromium 支持、资源释放、页面不可见降频和普通办公电脑性能。

## 6. 状态与屏幕

```text
empty       → 空工位、无 Actor、待机屏幕
onlineIdle  → 在线 Actor、待机屏幕
busy        → 工作 Actor、任务/数据屏幕
offline     → 休息 Actor、暗屏
error       → 异常 Actor、克制红色警示屏幕
```

没有可靠 Current Task Contract 时，Real API 的 `online` 只能映射为 `onlineIdle`，不得伪造 `busy`。

## 7. 主题、交互与性能

- Light / Dark 共享工位结构，只替换环境和主题素材。
- 每页始终 9 个工位，设备不足时保留空工位，超过 9 台由真实分页处理。
- 场景不建立嵌套滚动或页面横向溢出。
- 点击工位或标签打开既有 Device Detail Drawer。
- 不加载 WebGL、Three、Tres 或 GLB；轻量动画尊重 `prefers-reduced-motion`。
- 页面离开或不可见时，未来序列帧/视频播放器必须暂停并释放监听。

## 8. 废弃路线

以下内容不再属于现行规范：

- 浏览器实时 Three.js / Tres.js 办公室。
- GLB Mascot、桌椅、显示器及 Office Props 运行时契约。
- GLTF Loader、Avatar Clip 和 CanvasTexture 屏幕方案。
- Blender 自动化作为前端运行链路。

历史实现保留在 Git 历史中，不得重新作为现行 Device Office 方案引用。
