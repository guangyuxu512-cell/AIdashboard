# 设备中心 2.5D 资产规范

## 1. 正式路线

设备中心采用“正式预渲染美术资产 + 固定透视 + 前后遮挡 + 轻量 CSS 动画 + Vue/Electron 交互”。这套 2.5D 运行时不使用 CSS/SVG 拼装美术，也不使用 Three、Tres、WebGL 或 GLB Runtime。

Device、Worker、分页、Query、Drawer 与 Backend Contract 不依赖素材文件名或动画格式。Backend / Worker 只提供真实设备数据和状态，不负责美术表现。

## 2. 正式 V2 资产

运行资产位于：

```text
frontend/public/assets/device-office/v2/
├── 01-background/
├── 02-desk-base/
├── 03-screen-overlay/
├── 04-actor/
├── 05-foreground-mask/
├── 06-light-overlay/
├── 07-fx-overlay/
├── 08-label-ui/
├── layout/
├── preview/
├── manifest.json
└── README.md
```

`preview/` 只用于人工验收和资产对齐检查，运行时不得加载其中图片。正式标签继续使用 Vue DOM；`08-label-ui` PNG 只用于视觉参考。

运行契约和 Provider 位于：

```text
frontend/src/features/device-office/assets/device-office-assets.ts
```

运行时必须读取并校验 V2 `manifest.json` 的版本、设计画布、标准工位画布、Actor 对齐文件和八层声明。

## 3. 固定画布与 9 Slot

```text
Office design canvas: 1440 × 810
Canonical station canvas: 1448 × 1086
Station render size: 400 × 300
```

运行时唯一坐标源是：

```text
frontend/src/features/device-office/model/office-layout.ts
```

九个 Slot 与资产包 `layout/office-layout-9-slots.json` 一致：

```text
(70,105)   (520,105)   (970,105)
(70,325)   (520,325)   (970,325)
(70,545)   (520,545)   (970,545)
```

外层只计算一次等比 `scale()`。不得为 1366、1440、1920 分别维护坐标，不得让 JSON 和 TypeScript 同时成为可变运行来源。Slot 是前端投影，不是数据库实体或 Backend Contract。

## 4. 固定分层

```text
DeviceOfficeStage
├── OfficeBackgroundLayer
└── WorkstationSlot × 9
    ├── DeskBaseLayer
    ├── ScreenLayer
    ├── ActorLayer
    ├── ForegroundMaskLayer
    ├── LightOverlayLayer
    ├── FxLayer
    ├── InteractionHotspot
    └── DeviceLabelLayer
```

Desk、Screen、Actor、Foreground Mask 和 Light Overlay 使用同一个 `400 × 300` 相对定位容器。资产保持 `position: absolute`、完整画布、`object-fit: contain`，不得对齐后再单独裁切或移动 Actor/Screen/Mask。

Foreground Mask 必须位于 Actor 上方，用于桌前沿、椅子和底座的自然遮挡。Label 是最高交互层；透明 Hotspot 负责工位、人物和电脑区域点击。

## 5. Light / Dark 强制配对

Light 只允许：

```text
office-light-background.webp
desk-light-base.webp
desk-foreground-mask-light.webp
lamp-glow-light.webp
```

Dark 只允许：

```text
office-dark-background.webp
desk-dark-base.webp
desk-foreground-mask-dark.webp
lamp-glow-dark.webp
```

空工位和有设备工位都使用相同主题的 Desk Base + Foreground Mask，不得加载 `empty-desk-*-composite.webp` 作为第三套运行桌子。主题切换不得改变 Slot、Actor、Screen、Label 或 Hotspot 几何，不使用 invert、brightness 或 hue-rotate 伪造主题。

## 6. 状态映射

```text
empty
  → Desk + Mask + Light
  → 无 Actor / Screen / FX

onlineIdle
  → actor-idle-aligned.png
  → screen-idle-aligned.webp

busy
  → actor-work-aligned.png
  → screen-busy-aligned.webp

offline
  → actor-sleep-aligned.png
  → screen-offline-aligned.webp
  → zzz.png

error
  → actor-error-aligned.png
  → screen-error-aligned.webp
  → warning.png
```

Real API 没有可靠 Current Task 时，`online` 只映射为 `onlineIdle`，不得伪造 `busy`。Worker `error` 有真实来源时才映射 `error`。Visual State 不反写 Backend。

Actor 必须通过通用 `ActorAssetProvider` 解析。Accent 继续作为 Provider 输入，但 V2 只有一套已批准角色，不允许 CSS Filter 染色。

## 7. 动画与生命周期

- `onlineIdle`：约 4.6 秒、最多 2px 的轻微上下浮动。
- `busy`：约 1.25 秒轻微工作节奏，屏幕只做克制透明度呼吸。
- `offline`：ZZZ 约 3.2 秒缓慢上移淡出。
- `error`：Warning 约 2.2 秒呼吸，Actor 最多水平移动 1px。
- Dark Lamp：约 5 秒轻微透明度变化；Light Lamp 静止。

动画只使用 CSS Animation，不建立 RAF 或 Timer。`document.hidden` 时暂停，`prefers-reduced-motion` 时禁用；离开 Device Center 后组件自然卸载，不残留监听、播放器或定时器。

## 8. 加载与性能

- `DeviceOfficeStage` 保持 Lazy Load。
- 显示场景前先预加载当前主题 Background、Desk Base、Foreground Mask 和 Light Overlay。
- 所有运行图片使用 `decoding="async"`、`draggable="false"`。
- 一页只渲染当前 9 个 Slot；无 FX 状态时不创建 FX DOM。
- Preview、普通 1280×720 Screen 和 Source Actor 不进入运行页面。
- 服务器不参与动画或图片合成。

## 9. 数据与交互边界

- API 正常时显示办公区；API 失败继续使用页面既有 `ErrorState`。
- 0 台设备显示 9 个相同空工位；1 台设备显示 1 个 Actor + 8 个空工位；超过 9 台使用既有分页。
- 点击工位、人物区域或设备标签打开既有 Device Detail Drawer。
- Drawer 继续只展示真实 Device、Worker、影刀与已存在执行关系数据，不新增 CPU、GPU、内存、当前任务、Cookie、Browser Profile 或远程桌面字段。
- 办公区 / 列表偏好只保存在 `localStorage`，列表数据链路不变。

## 10. 禁止路线

- 运行时加载 `preview/` 或历史整张参考图。
- 显示 `REFERENCE_PREVIEW`、`ART ASSETS PENDING`、S1～S9 调试框或虚线 Hotspot。
- 使用 `empty-desk composite` 替换正式 Desk + Mask 组合。
- CSS/SVG/Canvas 拼装机器人、桌椅、显示器或办公室。
- Three.js、TresJS、Babylon、GLB、WebGL、PAG SDK 或游戏引擎。
- Blender 自动化作为前端运行链路。
