# 商品采集任务与商品库前端 Mock 契约 V1

状态：`UI_ONLY`。本文件描述显式 Mock 下的页面和交互，不代表手机采集、正式商品库写入、文件导入导出或 AI 能力已接入。

## 路由与复用

- 采集任务继续使用 `/product-selection?tab=collection-tasks`，不新增侧栏、路由或权限码；上层保留 `ContextSwitchBar(appearance="framed")`。
- 商品库继续使用 `/products` 和既有 `product-library` Guard。
- 列表复用显式 compact 的 `FilterBar`、`ManagementListSection`、`TableToolbar`、`DataTable`、`PaginationBar`；详情和确认保持默认密度并复用 `AppDialog`；图片复用 `ProductImage`，预览主图只在详情内组合 Naive `NImage`。
- 平台代码、名称和图标只取 `entities/platform`；拼多多代码固定为 `pdd`。
- 文件选择沿用已有隐藏原生 input + `AppButton` 组合；未新建 Upload 基础组件或 ZIP 解析层。

## 采集任务 Mock

- 常驻输入仅包含平台、抖店商品 ID／链接或已有店铺口令、输入框和创建按钮。创建时校验格式与活动重复项；校验失败保留草稿。
- 任务公开状态只有排队、处理、完成、失败、取消；回执、处理进度和入库状态只在详情展示。收到回执不等于已经入库。
- 查询、批量重试和批量取消共用同一紧凑筛选工具栏；窄宽度允许工具栏自身换行，不增加第二条批量操作栏。
- 拼多多只提示手机端手动返回边界，淘宝只显示规划状态；不伪造自动关键词采集。
- 候选池 Mock 批量采集和商品库 Mock 重新采集进入同一内存任务源；Real 候选采集没有因此启用。

## 商品库 Mock

- 商品库顶部固定为“全部商品／采集·导入／分组商品”三个业务视图；业务分组是筛选项而不是动态 Tab。
  分组商品视图提供可搜索分组下拉；采集或导入时未指定分组的商品进入“采集·导入”。
- 列表展示标题及业务分组、来源商品 ID／平台、完整类目路径、当前价格、采集时间和操作；默认每页 20。类目列保留两行可读预算并可悬浮查看全文，窄窗口通过表格横向滚动保留字段。
- 业务分组不是平台类目、店铺分组或团队；Mock 支持新建、搜索筛选、批量移动，Real 没有契约时不发送猜测写请求。
- 导入入口支持 TXT、ZIP 和文件夹的文件选择及目标分组；只显示文件清单，不解析、清洗或写入。
- 单商品导出入口对应一个清洗 TXT，批量入口对应 ZIP 清单；Mock 不生成或下载文件。`.txt` 与 `.origin.txt` 均定义为清洗后的兼容文本，不保存原始网络响应。
- 导入和既有采集任务是商品创建入口；本阶段不新增无来源的手工“新建商品”页面。列表支持编辑、单条删除和批量删除，均只修改当前 Mock 会话并显示明确演示回执。
- 商品 ID 始终为字符串；未知值显示 `—`，真实 0 保持数值；当前价格不从券后价等字段回填；兼容库存值 `999` 不解释为真实库存。

## 商品编辑

- 行级“编辑商品”直接打开可编辑态；桌面显式使用 `AppDialog size="workspace"`，在 Topbar 以下工作区保留约 8px 安全边距并跟随普通／最大化窗口，其他 Dialog 默认尺寸不变。
- 主图、SKU 图和详情图同时分区展示并保持等比；SKU 图片按稳定草稿键显式关联，不以图片数组下标推断 SKU。
- 下方保留 SKU、商品属性、资料包和采集历史。标题、属性、规格维度、SKU 名称／规格／当前价格可编辑；源商品 ID、平台 SKU 源 ID 和采集库存保持只读。
- SKU 支持新增和删除。新增行使用仅属于当前编辑稿的稳定 `draftKey`，`sourceSkuId` 固定为空；删除只影响编辑稿，不改写保存前的采集来源快照。
- 右侧商品列表为 320–360px 的贯穿同高列，包含缩略图、最多两行标题及平台／分组；只覆盖当前页或当前选择集，不一次加载整个商品库，上一件／下一件可按原分页继续。
- 外层 Dialog Body 不滚动；左侧编辑区和右侧列表各自使用一个内部纵向滚动区。左侧滚至 SKU 底部时右侧仍完整可用，固定 Footer 中的保存／取消／关闭始终可达，不再保留旧 sticky 小卡片及三／五行高度限制。
- 保存写入当前 Mock 会话，取消恢复本次编辑基线；关闭或切换商品前的未保存修改必须二次确认。支持复制标题、基础信息、SKU、全部信息及导出入口。
- AI 改图／审图在右上可见但禁用，明确未接入；本轮没有 Provider、编辑器或审核标准。

## Real 边界与未接入项

- Service Factory 只在构建和运行均为 Mock 时动态加载内存 Store。Real 返回显式 unavailable，绝不加载 fixture、猜测 API 或把操作显示为成功。
- 未接入：手机任务派发与回执、正式任务查询／重试／取消、正式商品库查询与写入、分组持久化、导入解析、TXT／ZIP 生成下载、AI 改图／审图、百应及淘宝采集。
- 本轮无 Backend、数据库、Migration、Worker、Electron 壳或依赖变化。
