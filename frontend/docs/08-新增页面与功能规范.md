# 新增页面与功能规范

新增前必须回答：
1. 属于哪个 Domain？
2. 是 Page / Feature / Entity / Shared 哪一层？
3. 现有组件是否已经满足？
4. 现有第三方库是否已经满足？
5. 是否需要新 API？
6. API 契约是否已存在？
7. 是否需要新权限码？
8. 是否需要新 Route？
9. 是否真的需要新增 Design Token？
10. 是否会与现有页面形成重复逻辑？

实施：
```text
确认契约
↓
复用现有组件/抽象
↓
补 Entity
↓
补 Feature
↓
Page 组合
↓
测试与验证
```

禁止先做一个巨大 Page.vue 再事后拆。
