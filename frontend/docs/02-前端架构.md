# 前端架构

数据流：

```text
Page
↓
Feature / Entity composable
↓
Query / API
↓
shared/http-client
↓
Backend
```

- 客户端状态：Pinia。
- 服务端状态：TanStack Vue Query。
- HTTP：统一 Axios Client。
- 类型：避免 `any`，使用正式契约。
- 错误：统一错误类型与全局请求错误入口。

页面不得直接创建 Axios 实例。

设备中心 2.5D 数据流：

```text
DeviceCenterPage
↓
useDeviceManagement（Query / Drawer actions）
↓
DeviceListItemViewModel
↓
Device Visual State + OfficeStationViewModel
↓
lazy DeviceOfficeStage / existing DeviceListTable
```

`DeviceOfficeStage` 通过 Vue DOM/CSS 按 `Background → Slot → Actor → Screen Overlay → Foreground → Label` 分层合成。非设备路由不加载办公区素材；场景只表达本地视觉行为和轻量屏幕占位，不产生 Backend 状态、任务或工位 Contract。

2.5D 视觉资源通过 `office2DAssetManifest → Layer Components → DeviceOfficeStage` 独立读取。当前 SVG 只属于可替换占位资产；后续可以替换为 PNG/WebP、Sprite Sheet、透明序列帧或受控视频素材，而不改写 9 工位投影、状态映射、分页和 Drawer 交互。
