# 前端架构

数据流：

```text
Page
↓
Feature / Entity composable
↓
Query / API
↓
shared/http-client
↓
Backend
```

- 客户端状态：Pinia。
- 服务端状态：TanStack Vue Query。
- HTTP：统一 Axios Client。
- 类型：避免 `any`，使用正式契约。
- 错误：统一错误类型与全局请求错误入口。

页面不得直接创建 Axios 实例。

设备中心 3D 数据流：

```text
DeviceCenterPage
↓
useDeviceManagement（Query / Drawer actions）
↓
DeviceListItemViewModel
↓
Device Visual State + OfficeStationViewModel
↓
lazy OfficeScene / existing DeviceListTable
```

`OfficeScene` 通过异步组件单独产出 Three/Tres Chunk，非设备路由不初始化 WebGL。场景只做本地动画与轻量 CanvasTexture 模拟屏幕，不产生 Backend 状态、任务或工位 Contract。

3D 视觉资源通过 `officeAssetManifest → officeAssetLoader → OfficeScene` 独立加载。Loader 在进入渲染前校验完整资产集合、命名节点和 Avatar 动画 Clip；资产不完整时必须停止 3D 视觉交付，不得回退到程序化几何体假装正式场景。9 工位投影、状态映射和 Drawer 点击仍由既有 View Model 驱动，与 GLB 内容解耦。
