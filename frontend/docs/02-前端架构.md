# 前端架构

数据流：

```text
Page
↓
Feature / Entity composable
↓
Query / API
↓
shared/http-client
↓
Backend
```

- 客户端状态：Pinia。
- 服务端状态：TanStack Vue Query。
- HTTP：统一 Axios Client。
- 类型：避免 `any`，使用正式契约。
- 错误：统一错误类型与全局请求错误入口。

页面不得直接创建 Axios 实例。

设备中心 2.5D 数据流：

```text
DeviceCenterPage
↓
useDeviceManagement（Query / Drawer actions）
↓
DeviceListItemViewModel
↓
Device Visual State + OfficeStationViewModel
↓
lazy DeviceOfficeStage / existing DeviceListTable
```

`DeviceOfficeStage` 使用 `1440 × 810` 固定设计画布，并只在容器边界计算一次等比 `scale()`。正式 V2 画布按 `OfficeBackgroundLayer → WorkstationSlot[9]` 合成；每个 Slot 内严格保持 `DeskBase → Screen → Actor → ForegroundMask → LightOverlay → Fx → InteractionHotspot → DeviceLabel` 顺序。非设备路由不加载办公区素材，场景只表达本地视觉行为，不产生 Backend 状态、任务或工位 Contract。

2.5D V2 视觉资源通过 `v2/manifest.json → ActorAssetProvider / Layer Components → DeviceOfficeStage` 独立读取。背景、工位、角色、屏幕、Mask、灯光与 FX 均使用正式对齐 PNG/WebP；`preview/` 只用于人工验收，不进入运行页面。替换资产格式不得改写 9 工位投影、状态映射、分页和 Drawer 交互。
