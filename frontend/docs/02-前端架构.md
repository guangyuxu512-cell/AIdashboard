# 前端架构

数据流：

```text
Page
↓
Feature / Entity composable
↓
Query / API
↓
shared/http-client
↓
Backend
```

- 客户端状态：Pinia。
- 服务端状态：TanStack Vue Query。
- HTTP：统一 Axios Client。
- 类型：避免 `any`，使用正式契约。
- 错误：统一错误类型与全局请求错误入口。

页面不得直接创建 Axios 实例。

设备中心 2.5D 数据流：

```text
DeviceCenterPage
↓
useDeviceManagement（Query / Drawer actions）
↓
DeviceListItemViewModel
↓
Device Visual State + OfficeStationViewModel
↓
lazy DeviceOfficeStage / existing DeviceListTable
```

`DeviceOfficeStage` 使用 `1440 × 810` 固定设计画布，并只在容器边界计算一次等比 `scale()`。画布按 `OfficeBackground → BackEnvironment → DeviceActor → MonitorScreen → ForegroundOcclusion → DeviceLabels → InteractionHotspots` 分层合成，所有层共享正式 `WorkstationSlot[9]` 坐标；非设备路由不加载办公区素材。场景只表达本地视觉行为，不产生 Backend 状态、任务或工位 Contract。

2.5D 视觉资源通过 `manifest.json → ActorAssetProvider / Layer Components → DeviceOfficeStage` 独立读取。办公室、工位、角色与屏幕视觉必须来自正式 PNG/WebP、Sprite Sheet、透明序列帧、透明 WebM 或经验证的 PAG 资产，禁止以 CSS/SVG 绘制替代美术。替换资产格式不得改写 9 工位投影、状态映射、分页和 Drawer 交互。
