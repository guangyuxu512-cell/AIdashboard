# 数据模型与接口契约

Backend Pydantic/OpenAPI 为 API Contract 权威来源。
Frontend 不得手写“看起来差不多”的字段。

建议通用分页：
```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

建议错误模型：
```json
{
  "code": "TASK_NOT_FOUND",
  "message": "任务不存在",
  "request_id": "..."
}
```

最终字段以正式后端契约为准。

- ID：统一 string。
- 时间：ISO 8601 传输，dayjs 显示。
- 金额：按后端精度契约展示。
- Page 不直接 axios。

推荐：
```text
shared/api/http-client
entities/shop/api
entities/device/api
entities/task/api
```

Mock / Real 必须使用相同 DTO 契约，禁止 Mock 自创另一套字段。
