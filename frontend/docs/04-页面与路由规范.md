# 页面与路由规范

## 工程初始化路由

阶段 0A 仅提供 `/` Home 占位路由，用于验证 Renderer 启动。正式业务路由在对应业务阶段按下述建议逐步引入。

建议路由：
```text
/dashboard
/shops
/shops/:shopId
/devices
/devices/:deviceId
/tasks
/tasks/:taskId
/workflows
/data-center
/ai-analysis
/permissions
/audit
/settings
```

Page 负责：
- 路由参数
- 页面级 Query
- 页面区域编排
- Feature 组合

禁止：
- 直接写大段业务算法
- 直接创建 HTTP Client
- 复制公共布局

## 滚动
默认 AppShell 固定，主内容区域负责页面滚动。
只有确有需求时建立局部滚动。
禁止多个不必要的嵌套滚动条。

## Header
页面标题区使用统一 Token，禁止标题区占用大量垂直空间。
