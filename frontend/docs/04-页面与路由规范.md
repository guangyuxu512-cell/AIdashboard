# 页面与路由规范

## 工程初始化路由

阶段 0B 提供 `/` Design System 验证路由，用于验证 Renderer、AppShell、基础组件和页面模式。阶段 1A 已引入 `/shops` 店铺中心路由，当前仅承载 Frontend Fixture 与 View Model，不连接 Backend。

建议路由：
```text
/dashboard
/shops
/shops/:shopId
/devices
/devices/:deviceId
/tasks
/tasks/:taskId
/workflows
/data-center
/ai-analysis
/permissions
/audit
/settings
```

Page 负责：
- 路由参数
- 页面级 Query
- 页面区域编排
- Feature 组合

禁止：
- 直接写大段业务算法
- 直接创建 HTTP Client
- 复制公共布局

## 滚动
默认 AppShell 固定，主内容区域负责页面滚动。
只有确有需求时建立局部滚动。
禁止多个不必要的嵌套滚动条。

阶段 0B 的统一滚动链路为：

```text
Electron Window
↓
AppShell（固定 Sidebar / Topbar）
↓
app-shell__content（唯一主滚动区域）
↓
Page
```

## Header
页面标题区使用统一 Token，禁止标题区占用大量垂直空间。
