# 思余软件守护

独立的 Windows 当前用户程序，关闭管理窗口不会结束守护。添加要监控的程序、Worker、比特、Windows 服务或采集插件，然后在界面设置登录自启。两个后台进程互相检查退出状态；为使用比特等桌面软件，机器开机后需要登录 Windows。

- 普通程序仅在实际进程退出后尝试启动，按完整路径识别；同名其他版本、访问权限不足或服务正在启动时先标记为未确认。失败重试有退避。
- Worker 使用现有本机状态和心跳；网络断开只显示连接异常，不结束进程。Worker 0.5.25 起在执行任务前持久记录活动状态；确认无活动任务且结果无不确定性时可自动启动。执行中异常退出、结果状态不确定或旧版本缺少安全证据时暂停启动。守护本身不领取、不重派任务。
- 1688 采集 0.1.11 起提供本机活动记录；空闲且已启用的签名版本通过完整性验证后可自动启动，任务未结束、结果不确定或版本无法验证时不自动启动。首次直接安装且尚无已启用签名版本时先显示待确认。聚水潭上架等尚未适配的软件添加为“任务型程序”，异常退出只提示待核查，不强行重启。
- 比特只检查进程和本机 API，不因 API 失败而关闭浏览器。采集插件复用运营中心 `/api/v1/collection/windows` 的心跳，需有 `collection.read` 且分组范围允许读取全部分组的只读 Token，并指定对应浏览器标识；Token 用当前 Windows 用户 DPAPI 保护。网络异常不等于插件离线，插件状态不会触发浏览器重启。
- UU 远程可添加 `GameViewerService` 作为 Windows 服务；需要 Windows 赋予启动服务的权限。进行中的远控不会因为连通性异常而被中断。

看门狗只重启所选普通程序和经本机记录确认空闲的适配软件；不保证其他软件的断点续跑、浏览器插件自动恢复或平台侧操作幂等。原有业务数据、店铺资料、Session、任务队列均由各软件保存。
