# Mobile 设计系统

## 唯一 Token

`mobile/src/shared/styles/tokens.css` 是 Mobile Design Token 唯一权威来源，负责：

- 品牌色、文本、Surface、Border、状态与阴影。
- 字体、字号、字重和行高。
- 间距、圆角、触控高度和布局尺寸。
- Light、Dark 的语义值。
- 顶部、左右、底部 Safe Area。

Token 语义固定覆盖 Brand/Accent、Background、Surface、Border、Text、Hover、Selected、
Disabled 与 Status；组件只能按语义消费，例如 `--color-primary`、`--bg-surface`、
`--bg-selected`、`--text-secondary`、`--text-disabled`、`--status-success`。

颜色字面量只能出现在 `tokens.css`。Page、Feature、Entity、Shared UI 和 Vant 适配文件
只能消费语义 Token，禁止局部创建另一套颜色、随机间距或随机圆角。

`mobile/src/shared/styles/theme.css` 聚合 Vant、Token、Vant Token 映射和全局基线；
`mobile/src/app/styles/index.css` 是应用唯一全局样式入口，只负责装配 Shared 样式。
`main.ts` 不得分散导入其他全局样式。

PC 与 Mobile 共享 Token 的语义思想，不直接共享 Token 文件或全部数值。Mobile 独立维护
适合触控的 44px 控件、页面间距、圆角和安全区值；禁止直接 Import Desktop Token CSS。

## Vant 边界

优先使用 Vant 的 Button、Field、Cell、CellGroup、NavBar、Tabbar、Popup、Dialog、Toast、
Loading、Empty 等手机交互能力。

`vant-theme.css` 只将 Vant CSS Variable 指向 Mobile Token，不包含颜色字面量或独立视觉值。
业务页面禁止：

- 散落覆盖 `--van-*`。
- 使用 deep selector 修改 Vant 内部 DOM。
- 为每个 Vant 组件建立无语义 Wrapper。
- 将业务状态、权限或校验规则写进基础 UI。

Foundation Playground 可以直接组合 Vant 组件来验证基础设施；业务组件是否抽象仍按真实
复用与语义边界判断。

## 触控与布局

- 默认触控目标和基础按钮高度至少为 44px。
- 页面水平 Padding、Section Gap 和圆角只使用 Token。
- 使用流式宽度，不使用 px-to-viewport 全量转换第三方 CSS。
- 使用 `100dvh` 构建手机高度链，并提供 `100vh` 兼容回退。
- 禁止页面通过 `100vh - x` 猜测固定区域高度。
- 禁止横向溢出和无必要的嵌套滚动区。

`MobileAppShell` 只有 `header`、默认内容和 `bottom` 三个 Slot，不依赖业务 Props。
Shell 负责应用高度链、主滚动区以及顶部/底部 Safe Area；`AppPage` 负责页面左右 Safe Area
和普通内容 Padding。Bottom Sheet 自身消费左右/底部 Safe Area。业务页面不得复制这套计算。

## 主题

Theme Mode 固定为 `light | dark | system`。Theme Store 将模式保存在浏览器本地，并把解析
结果同步到根元素 `data-theme`、`color-scheme` 与 Vant Dark Class。`system` 监听
`prefers-color-scheme`。

主题只是客户端显示状态，不进入 Query、Backend DTO 或 Auth Contract。
