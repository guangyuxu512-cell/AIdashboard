# Mobile 路由与权限

## Router

Mobile 统一使用 Vue Router Hash History，所有 Route 只在 `src/app/router/` 注册。
每条 Route 必须显式声明：

```ts
interface RouteMeta {
  title: string
  layout: 'main' | 'detail' | 'auth' | 'tool'
  requiresAuth: boolean
  permission: string | null
}
```

`layout` 只描述 Shell，不代替 Authentication 或 Module Access。

## 正式产品路由

| Route                | Layout   | Auth | Module Access |
| -------------------- | -------- | ---- | ------------- |
| `/login`             | `auth`   | 否   | 无            |
| `/permission-denied` | `auth`   | 是   | 无            |
| `/`                  | `main`   | 是   | 无            |
| `/devices`           | `main`   | 是   | `device`      |
| `/devices/:deviceId` | `detail` | 是   | `device`      |
| `/tasks`             | `main`   | 是   | `task`        |
| `/tasks/:taskId`     | `detail` | 是   | `task`        |
| `/schedules`         | `main`   | 是   | `schedule`    |
| `/shops`             | `main`   | 是   | `shop`        |
| `/me`                | `main`   | 是   | 无            |

未登录深链保留安全的站内 `redirect`；登录成功后返回原路由。外部 URL、
`//host` 和 `/login` 循环不允许作为回跳目标。没有目标时按 `device → task → schedule
→ shop → /me` 选择第一个有权入口。

Bottom Navigation 的注册顺序仍是设备、任务、计划、店铺、我的；前四项按当前
Team 返回的 `module_codes` 显示，“我的”始终作为账号和退出入口。缺少权限时
直接 URL 也不得进入目标页。

## Human Session 与 Team Context

应用启动和访问受保护路由时，通过 `GET /api/v1/auth/me` 恢复服务端
HttpOnly Session，不读取 Cookie，不保存 `isLoggedIn` 或 Token。有效用户随后读取：

```text
GET /api/v1/access/me/teams
↓
确定当前 Team
↓
Axios Interceptor 注入 X-Team-ID
↓
GET /api/v1/access-management/me/module-access
```

仅一个可用 Team 时直接选中；多个 Team 时登录页提供最小必要选择。
localStorage 只保存按 `userId` 隔离的 Team 偏好，不是身份证明。Team 变更必须清理
TanStack Query 缓存，避免跨 Team 沿用数据。

`HUMAN_AUTHENTICATION_REQUIRED`、`HUMAN_SESSION_INVALID` 或 `HUMAN_USER_DISABLED` 会统一
清理当前身份与 Team 状态并返回登录页。`HUMAN_LOGIN_FAILED` 只是登录失败，
不得误判为已登录 Session 失效。

## Guard 边界

`installRouteAccessGuards` 固定先安装 Authentication Guard，再安装 Permission Guard。
Page 不自行恢复 Session、不解析权限、不插入 Header。Frontend 隐藏入口与拒绝
Route 只是体验边界，不构成安全边界；Backend 必须在领域 API 执行真实
Module Access 和 Data Scope。Worker Device Token 与 Human Session 永久分离。

## Development Route

`/__foundation`、`/__visual-tuner` 与 `/__icons` 仅在 Development 注册，不进入
产品导航。`/__visual-tuner` 和 `/__icons` 使用 `layout='tool'`；这些工具不能读写
业务 Auth 状态或绕过产品 Guard。
