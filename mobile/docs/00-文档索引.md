# Mobile 文档索引

Mobile 是独立的手机 Web Frontend。处理任务时先读取根 `AGENTS.md`、
`mobile/AGENTS.md`，再根据本索引读取当前任务需要的文档。

| 文档                        | 用途                                                           |
| --------------------------- | -------------------------------------------------------------- |
| `01-前端架构.md`            | Mobile 分层、依赖方向、状态归属与 API 边界                     |
| `02-设计系统.md`            | Mobile Design Token、Vant 使用边界、主题、触控与 Safe Area     |
| `03-路由与权限预留.md`      | Route Meta、DEV Foundation Route 与 Auth/Permission Guard 插槽 |
| `04-开发验证规范.md`        | lint、typecheck、单元测试、构建与移动视口 E2E 验收             |
| `05-Backend契约使用规范.md` | Backend 权威来源、通用契约、领域 API 范围与 Contract Gap       |
| `06-任务中心规范.md`        | Mobile Task Center 的只读用例、查询、运行时、UI 与测试约束     |

## 任务路由

| 任务                                 | 必读                                                        |
| ------------------------------------ | ----------------------------------------------------------- |
| 新增页面或调整分层                   | 01 + 03                                                     |
| 调整 UI、Token、主题、Vant 或布局    | 02 + 04                                                     |
| 修改 Router、Auth 或 Permission 预留 | 01 + 03 + 04                                                |
| 接入 Backend API                     | 01 + 05 + Backend 正式 Contract；不得从 Mobile 文档猜测 DTO |
| 修改 Pinia 或 TanStack Query         | 01 + 04                                                     |
| 修改任务列表、详情或运行日志         | 01 + 03 + 04 + 05 + 06                                      |
