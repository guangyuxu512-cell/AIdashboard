# Mobile 文档索引

Mobile 是独立的手机 Web Frontend。处理任务时先读取根 `AGENTS.md`、
`mobile/AGENTS.md`，再根据本索引读取当前任务需要的文档。

| 文档                              | 用途                                                                |
| --------------------------------- | ------------------------------------------------------------------- |
| `01-前端架构.md`                  | Mobile 分层、AppShell、依赖方向、状态归属与 API 边界                |
| `02-设计系统.md`                  | Mobile Token、全局 Header/Nav、主题、触控与 Safe Area               |
| `03-路由与权限预留.md`            | Route Layout Meta、DEV Route 与 Auth/Permission Guard 插槽          |
| `04-开发验证规范.md`              | lint、typecheck、单元测试、构建与移动视口 E2E 验收                  |
| `05-Backend契约使用规范.md`       | Backend 权威来源、通用契约、领域 API 范围与 Contract Gap            |
| `06-任务中心规范.md`              | Mobile Task Center 的只读用例、查询、运行时、UI 与测试约束          |
| `07-设备中心规范.md`              | Mobile Device Center 的只读查询、状态语义、UI 与测试约束            |
| `08-Stage-2手动微调索引.md`       | 已冻结组件的尺寸、间距、字体与图标尺寸手动调节位置                  |
| `09-可视化Token调参器.md`         | 仅开发环境的 Visual Token Tuner V3 尺寸 / 颜色 / 外观调节与导出流程 |
| `10-Mobile-Visual-V2-设备列表.md` | `/devices` Visual V2 最终对齐、共享冻结基础、三态、响应式与验收契约 |
| `11-Mobile-Visual-V2-设备详情.md` | `/devices/:deviceId` Visual V2 组合、真实契约映射与冻结视觉规范     |
| `12-Mobile-Visual-V2-任务列表.md` | `/tasks` Visual V2 组合、日期/状态查询、任务卡映射与冻结验收规范    |
| `13-Mobile-Visual-V2-任务详情.md` | `/tasks/:taskId` Visual V2 信息卡、真实事件、独立滚动与候选验收规范 |
