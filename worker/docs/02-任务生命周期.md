# 任务生命周期

Worker 不自行发明 Task 状态。

3B-Lite 只允许：

```text
PENDING → RUNNING → SUCCESS
                  → FAILED
                  → LOST
```

- Worker 每 3 秒 Poll，仅能领取 `target_device_id` 等于自身身份的 PENDING Task。
- Backend 当前按 `created_at ASC, task_id ASC` 稳定 Claim；不依赖 PostgreSQL 的偶然返回顺序。
- Backend 使用 PostgreSQL 原子 Claim，避免重复领取。
- Claim 后获得 60 秒 Lease，执行期间每 20 秒 Renew。
- Worker 突然退出时不伪造 FAILED；Backend Reconcile 在 Lease 过期后标记 LOST。
- LOST 不自动重新排队，不自动切换电脑。
- Worker 正常退出只需尽可能结束轮询；突发退出的可靠性由 Lease 提供。

Progress 只作为 Runtime Event 上报，不是顶级 Task 状态。本阶段仍不支持 Backend Cancel、
TaskRun、自动重试或 `RETRYING/CANCELLED/PARTIAL` 等新状态。

## 停用与软移除

- Device 停用：Heartbeat 继续；Claim 返回无任务；现有历史不删除。
- Device 软移除：Heartbeat、Claim/Poll、Lease、Result 与 Provider Inventory Upload 均因认证失败而停止。
- 物理电脑重新接入必须使用 Backend 新发放的 Device UUID 与 Token。
