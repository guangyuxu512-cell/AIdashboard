# 任务生命周期

Worker 不自行发明 Task 状态。

3B-Lite 只允许：

```text
PENDING → RUNNING → SUCCESS
                  → FAILED
                  → LOST
```

- Worker 每 3 秒 Poll，仅能领取 `target_device_id` 等于自身身份的 PENDING Task。
- Backend 使用 PostgreSQL 原子 Claim，避免重复领取。
- Claim 后获得 60 秒 Lease，执行期间每 20 秒 Renew。
- Worker 突然退出时不伪造 FAILED；Backend Reconcile 在 Lease 过期后标记 LOST。
- LOST 不自动重新排队，不自动切换电脑。
- Worker 正常退出只需尽可能结束轮询；突发退出的可靠性由 Lease 提供。

本阶段不支持 Progress、Cancel、TaskRun 或复杂重试。
