影刀只读诊断工具

使用：
1. 完整解压 ZIP。
2. 保持影刀已启动并登录需要诊断的账号。
3. 双击“影刀只读诊断.cmd”。
4. 将生成的 yingdao-diagnostic.json 发给开发者。

采集范围：
- 当前影刀版本及账号的非认证元数据。
- 当前账号本机应用索引的安全字段。
- 本地应用包是否存在，以及 package.json 中的 ID、名称、版本和入口。
- 与应用相关的 SQLite 表名、列名和行数。

明确不采集：
- 密码、Cookie、Token、Session。
- package.json 中的变量、流程、选择器或依赖详情。
- 其他影刀账号目录。
- 应用业务数据。

工具以 SQLite read-only 模式访问当前账号数据库，不会修改影刀数据。
