# 权限与安全

推荐：RBAC + Data Scope。

权限至少考虑：
- 菜单
- 动作
- 店铺范围
- 数据范围

## Credential
账号密码属于 Shop/Account Credential，不属于某台 PC 的永久明文配置。

## Session
Session 独立建模：
- cookie
- token/csrf（需要时）
- user_agent/profile
- version
- status
- source_device
- updated_at

## Worker 授权
Worker 只可读取：
- 当前 Task
- 当前授权 Shop
- 当前执行所需凭证

禁止下载所有账号密码、所有 Cookie。
前端禁止显示完整凭证。
敏感读取和变更应有 Audit。

阶段 3A 使用 Fernet（`cryptography`）和服务器环境变量 `BACKEND_ENCRYPTION_KEY` 加密 Credential Secret 与 Session payload。密钥不得提交 Git；缺少或无效密钥时敏感写入必须失败，不允许退化为明文。

API 错误会按敏感字段名脱敏验证输入。日志、异常、`repr` 和审计均不得携带密码、验证码、Cookie、Token 或 Session payload。普通 Frontend 只能访问脱敏 Credential 状态和 Session 元数据。
