# 后端架构与目录

推荐模块内部：
```text
modules/shops/
├── api.py
├── schemas.py
├── models.py
├── service.py
├── repository.py
└── exceptions.py
```

不要使用全局大平层：
```text
controllers/
services/
models/
```

`shared` 只能放真正跨领域能力。
业务语义放具体 module。

阶段 2A 已建立 `modules/users`、`modules/shops`、`modules/devices`。ShopDeviceBinding 的唯一权威实现归属 `modules/shops`，由 ShopService 管理店铺与设备之间的绑定规则。

阶段 3A 增加 `modules/credentials`、`modules/sessions`、`modules/authentication`：前两者分别持久化凭证与 Session，后者只定义未来平台认证及验证码 Provider 的纯 Contract/Protocol，不包含浏览器、Worker 或平台实现。
