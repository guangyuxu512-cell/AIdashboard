# 商品数据契约盘点与后续提案 V1

2026-10-15，只读源码/响应样本盘点。当前业务状态 UI_ONLY；本轮没有新增 API、Model、
Migration、后台任务、数据库、平台请求或通知。此文是后续接入提案，不是可调用 API Contract。

## 已有 → 复用 → 扩展 → 新增

| 能力/证据 | 后续复用边界 | 真正缺少的部分 |
| --- | --- | --- |
| modules/sessions/auth_context.py 的 ShopSessionAccessor | 复用服务端唯一解密边界与版本化 Session，浏览器不持有 Cookie | 商品数据请求的已验证平台契约 |
| product_selection/platform_io.py、platforms/douyin 既有 HTTP/Signer/Connector | 复用合法店铺上下文、身份核验、统一 HTTP 和签名；不直接把选品榜单当商品经营接口 | 商品数据 Adapter/白名单参数/精确响应解析 |
| modules/operating_dashboard 的事实、Job/Item、Executor、Scheduler | 复用分层、去重、失败保护、日期/覆盖状态及既有调度底座 | 商品粒度与指标事实、同步记录及业务 Service；不能复用店铺汇总表代存商品指标 |
| modules/access 的 ActorContext、模块与 Shop Scope | 当前页面复用 shop；未来 API 必须服务端授权后再筛选、排序、分页 | 分组的写权限与归属须在接入前冻结，菜单可见不等于数据授权 |

| product_selection 的 Candidate/Observation | 可以复用稳定商品 ID 和展示，不借用选品来源/排名事实 | 店内商品分类不是选品策略、店铺组或 AI 素材组 |

无需第二套 HTTP 客户端、签名服务、账号保存、通用队列、权限后台或通知中心。
现有请求基础设施不等于商品事实、商品分组或监测已经实现。

| Sample Source Code | 已确认的 meta 名称 | 限制 |
| --- | --- | --- |
| product_show_ucnt | 曝光人数 | 不能作为曝光次数 |
| product_click_ucnt | 点击人数 | 不能替换点击次数 |
| product_click_pay_ucnt_ratio | 点击-成交转化率（人数） | 与曝光-点击率、曝光成交率分开 |
| pay_cnt | 成交订单数 | 不等于成交件数 |
| receive_amt | 成交金额 | 不替换为 pay_amt |
| pay_amt | 用户支付金额 | 与 receive_amt 独立保存来源代码和口径 |

样本的数值单位代码（金额3、比例4、计数5）只能作为观测元数据；金额缩放、统计时间归属、
比例分子/分母及多日/多店汇总语义尚未取得请求和平台说明证据。
不得把金额3直接解释为分或元，也不能平均逐日或逐店比例。
缺失、显式 null、非法值和有效0需独立保存状态，失败不能清空既有成功事实。
收集时间只能来自实际成功请求，不能使用页面刷新时间代替。

## 真实接入前最小缺证据清单

1. 实际 URL、HTTP 方法、签名/认证路径与一次合法请求的白名单参数。
2. 请求店铺身份、平台商品 ID、统计日期/时区/窗口，以及业务成功/空页/错误响应的证据。
3. page_no/page_size/total 与稳定翻页、可排序字段、完整筛选结果排序能力。
4. 售卖/载体/高级筛选参数和支持范围；旧项目的下拉字段不能作为平台证明。
5. 每个指标的单位/缩放/精度、人数去重、比例分母、多日汇总、实时库存时间语义。
6. 店内分组的单/多归属、团队与店铺写权限、成员协作与并发冲突策略。
7. 同步的幂等边界、失败与旧成功值并存、有限重试、部分覆盖与请求状态。

当前 Real service 明确不可用，没有猜测资源 URL，不能用返回空数组或 Mock 数据替代失败。
后续正式列表应采用既有 Page 结构，在授权范围内完成筛选与全量排序后分页，缺失值排序最后、
同值用稳定商品身份确定顺序；Frontend 不执行当前页排序冒充服务器结果。
正式 Pydantic/OpenAPI、Adapter 与单位映射通过后再实现 Real Mapper。

## 分组与存储提案

当前前端只用单组归属演示，理由是本轮只需店内自定义分类和批量设置/移出，尚无多对多业务证据；
这是最小提案，不是最终数据库关系。删除组仅移除归属，商品指标、历史同步及其他店铺组保留。
已有成功值和最近失败尝试应能同时读取；历史不可被后续补采失败覆盖或误写成0。
商品事实、分组关系和同步状态需要各自明确实体/关系语义，不能仅存一份浏览器表格。
需要数据库时先提交最小 Schema/兼容提案，由 ca97 分配专用 Feature DB 和唯一 Migration Slot；
本阶段无槽，不能借用81a1当前候选池资源或20261015_0046。
