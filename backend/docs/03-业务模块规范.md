# 业务模块规范

## API
负责参数解析、权限入口、调用 Service、返回 Schema。

## Service
负责业务规则、跨 Repository 协调、事务边界。

## Repository
负责查询和持久化。

## Model
SQLAlchemy ORM。

## Schema
Pydantic 输入输出。

## 抽象
平台差异使用 Connector/Adapter。
禁止大量 `if platform == ...` 散落全项目。

## Core Domain V1 业务规则

- User、Shop、Device 的 API 通过各自 Service 调用 Repository。
- ShopDeviceBinding 由 ShopService 管理创建、角色修改和停用。
- 同一 Shop 最多一个启用的 PRIMARY；Service 预检查并由 PostgreSQL 部分唯一索引兜底。
- 本阶段不提供物理删除 API，停用使用 `enabled`。
