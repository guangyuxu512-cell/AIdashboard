## 固定路径解析

实现位置为 `app/platforms/douyin/product_selection.py`。这是三个平台响应的纯解析边界，不是 API、执行器或通用指标平台。未知字段不递归搜索，不通过相邻接口推断类型或零值。

| 数据 | 正式读取路径 | 类型及处理 |
| --- | --- | --- |
| 业务码 | `st` | 严格接受整数0或字符串"0"；bool不是成功码。非零数字/安全字符串保留原类型，返回业务拒绝；缺失/错误类型为结构错误 |
| 类目树 | `data.cate_list[]` 的 `cate_id/cate_name/children` | ID字符串，名称字符串，只遍历children；各父级的0/全部节点不全局合并 |
| 类目上下文 | `data.industry_id/industry_name/cate_id` | 保留实际行业及当前类目；不伪造缺失值 |
| 列表与分页 | `data.data_result[]`、`data.page_result.page_no/page_size/total` | 列表/整数分页；有效成功空列表与失败、缺字段分开，不补分页默认值 |
| 商品身份与排名 | `product_info.id/name/rank` | 商品ID必须是字符串；排名用原值，不用本地行号；缺失标题/排名保留未知 |
| 图片与价格带 | `product_info.image_url/price_bin` | 可空；图片只允许无账号凭据的http(s)资源，不走中控认证资产请求 |
| 商品商家 | `product_info.shop_list[].shop_id/shop_name` | 商家平台ID/名称独立于请求Shop UUID；多商家保留集合，不冒充唯一身份 |
| 末级类目与平台标记 | `product_info.leaf_category_id/newly_on_ranking` | 保留原ID及bool；不由平台标记推断中控首次发现，也不据此冻结“首次上榜”筛选 |
| 视频四项 | 行内 `pay_amt/pay_combo_cnt/product_click_cnt/video_cnt.value_range[]` | 保留两个端点、原数值类型及unit；使用Decimal，不取中点，不换算price尺度或推测件/单 |
| 补充商品身份 | `data.product_id` | 必须与本次请求ID匹配，否则商品身份错误 |
| 完整类目 | `data.cid_info` | 已观察到非空字符串数组；缺失、null、错误结构分别保留状态 |
| 首次上架日期 | `data.first_on_shelf_time` | 已确认中文年月日格式，DATE日精度，不伪造时间或时区 |
| 差评率原值及单位 | `data.bad_comment_rate.value.value/unit` | Decimal原值及原unit。0.00205018686599039/unit=4的换算未确认，不格式化百分比、不用于筛选 |

可选指标分别记录 `available/missing/null/invalid`。真实0为available；一个可选指标错误不隐藏其他有效指标或候选身份。补充信息字段状态不是数据库回写成功状态，后续Service必须仅更新已确认值，失败不得清空旧成功事实。

## 错误边界

HTTP和签名继续使用现有平台错误；本解析边界增加：

- `DOUYIN_SELECTION_BUSINESS_REJECTED`：实际非成功业务码，阶段 `platform_business`。不直接归为Cookie过期、风控或数据未就绪。
- `DOUYIN_SELECTION_PRODUCT_ID_MISMATCH`：basic_info返回商品身份不一致，阶段 `response_parse`。
- `PLATFORM_RESPONSE_INVALID`：固定路径或必需身份/分页结构错误，阶段 `response_parse`，只附安全字段路径。

平台原始消息、完整URL和任意响应不进入错误详情或普通日志。业务码中的异常长文本/URL不原样回传。业务码的字符串和整数成功/拒绝情况均有独立测试，不用仅数字过滤器丢掉字符串状态。

`SelectionSourceScope` 只记录实际业务参数，全部显式输入；不负责证明参数可执行或将相对日期映射到平台。版本化 SHA256 包含 Endpoint、日期及白名单业务条件，排除分页、Cookie、Token、签名、UA、指纹和页面追踪。不同期间、条件或请求店铺保留不同来源，不互相覆盖。

内部 `ProductSelectionFactService → ProductSelectionRepository` 使用短事务，不发平台请求。写入前重新解析当前人员/Team、模块权限及 Shop 授权/启用状态；读取先按当前 Team 和 Shop 授权过滤，再选择可见的最新来源、排序分页。超级账号跨Team读取沿用现有语义，写入必须显式指定目标Team。停用Shop保留可见历史，停止新写入；移除/撤权不会删除事实，但正常查询不可见。

候选的Team外键同时纳入既有 `AccessManagementRepository.team_has_references()` 检查。即使成员和授权已撤回，只剩选品候选事实，正式删除Team仍返回 `409 TEAM_IN_USE`，候选和来源均保留；无任何成员、授权或业务引用的空Team继续允许删除。不更改RESTRICT外键或以清理事实使团队可删除。

PostgreSQL唯一键/upsert保证候选身份和来源幂等，来源回写按实际请求开始时间拒绝相同/更旧执行。基础信息补充也必须匹配原榜单执行版本及商品身份；旧执行的补充不覆盖新榜单。缺失或失败保留此前有效字段，并记录安全错误码。四项区间保存Decimal字符串、原类型、unit、独立状态及有效取数时间；真实0是有效值。差评率使用无强制小数位的NUMERIC和原unit，不格式化百分比。

`checked_at` 是榜单检查时间；`metrics_retrieved_at` 是榜单指标获取时间，区间字段另保留各自有效取数时间。`basic_info_retrieved_at` 仅在三项补充字段都有效时推进；部分/失败使用 `last_attempt_at` 和安全错误码表达，不把保留下来的旧值伪装为刚取得的新值。字段状态不是执行Job状态。

没有已批准的自动删除期限；停用、移除及撤权不级联删除新事实。`0042 → 0041` 会删除这两张新表，只允许在可重建测试库执行。应用回滚默认保留Schema和已取得事实，生产数据处置另走Release Gate及备份流程。

## 数据库查询 API

正式只读前缀为 `/api/v1/product-selection`，DTO 以 `app/modules/product_selection/schemas.py` 和 OpenAPI 为准，复用 Human Session、ActorContext 和已存在的 `product-selection` Module Guard。Service 再次解析当前授权；撤销 Team/模块/请求店铺访问后不得通过历史 ID 读取。超级账号跨 Team 读取遵循现行语义，普通成员仅可读当前 Team 且请求店铺仍获授权的来源。商品所属商家不是授权店铺。

- `GET /candidates`：复用 `Page`，默认 page=1/page_size=20，前端每页10条须显式传10。可选 `shop_id`、`source_scope_hash` 和 `search`（标题/字符串商品ID的字面子串，不把%或_当通配符）。权限和来源条件过滤后，每个候选选择一个最新可见来源，再按搜索、原值排序及分页；total 与 items 为同一集合。默认 `sort_field=checked_at,sort_direction=desc`；只支持 checked_at、first_on_shelf_date、rank，方向asc/desc，空值末尾，同值以candidate_id稳定排序。不支持未确认单位的差评率筛选/排序。
- `GET /observations/{observation_id}`：读取列表所指的精确来源，不自动换成其它店铺或周期；不存在或不可见统一404。列表和详情使用同一 `SelectionObservationRead`。
- `GET /categories?shop_id=UUID`：显式读取当前授权、启用的抖店类目，不受手动执行开关影响。复用现有有效ShopSession及已确认的三个类目参数；鉴权后结束请求Guard的只读事务，Service在平台调用前后分别重验当前User/Team/module/Shop。ShopSession读取结束后才调用平台，无DB连接包围HTTP。返回shop_id、nodes[]的category_id/name/children及实际行业/当前类目信息。没有本环境合法有效会话时明确失败，不复制生产会话。前端使用路径限定的显示节点ID区分各父级0/全部；这个显示ID不是已确认的平台category_id转换。

Read 投影保留 candidate_id、observation_id 和字符串 product_id；request_shop_id/name 与 merchants[].platform_shop_id/name 分开。source_context 只有已登记的业务条件和来源版本，不包含认证、签名或页面追踪。周期采用明确 period_begin/end，不推断近7天等平台枚举。四项视频区间以Decimal字符串、原value_type/unit、独立有效性和取数时间返回；未知值为null。差评率原值为Decimal字符串并保留unit，不变成百分比。榜单checked_at、指标metrics_retrieved_at、基础信息完整取数basic_info_retrieved_at分别返回；last_attempt_at和安全last_error_code/stage不冒充成功时间。

候选/来源/运行GET只读取数据库，不调用ShopSession、Signer或平台；类目GET是上述明确的平台读操作。没有策略保存、手机采集或竞品标记的假成功接口。空数据库列表只表示没有可见候选，不能证明“成功空榜单”；该结果须结合下述运行状态。Real前端已绑定查询，未确认单位显示平台原值，未接入操作禁用，不回退Mock。
