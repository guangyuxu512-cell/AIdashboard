# 任务调度与设备通信

基础模型：
- Device
- Task
- TaskRun（需要时）
- Skill

Worker 协议：
- register
- heartbeat
- claim
- lease renew
- report progress
- report result

第一阶段可使用 PostgreSQL Task 表 + HTTP Long Poll。

Task 状态枚举以正式代码 Contract 为准。
禁止自行新增同义状态。

Worker 领取任务必须建立 Lease。
有副作用任务必须考虑 idempotency_key。

Redis 后期可用于通知、缓存、协调，PostgreSQL 仍是业务事实来源。
